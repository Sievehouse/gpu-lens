Open the console:
{{- if .Values.ingress.enabled }}
  https://{{ .Values.ingress.host }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "gpulens.fullname" . }} 8080:{{ .Values.service.port }}
  then open http://127.0.0.1:8080  (Go Live opens first; the simulation is at /?view=demo)

{{- if not .Values.auth.enabled }}

Set auth.enabled=true (and use an Ingress with TLS) before exposing it.
{{- end }}

  --set sources.dcgmExporterUrl=http://nvidia-dcgm-exporter.gpu-operator.svc:9400/metrics

{{- end }}
